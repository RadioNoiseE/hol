1.  Records, methods, constants, fields: an idiomatic abbreviation or
    the full word.  Use HOL Light's name, in camel case, where one
    exists.

2.  Variables (parameters, components, locals), in order of
    preference:

    a.  a reserved name (below);
    b.  locals that matter across several lines: a short word or
        abbreviation for the role (aty, rty, theta);
    c.  a value derived from another variable: the next letter,
        skipping reserved ones, or that name plus a digit;
    d.  the first letter of the meaning;
    e.  the type name's capitals, or its first letter;
    f.  otherwise case by case.

    Several variables with the same role and type: one name, with
    digits on all of them (t1, t2).

3.  Booleans: a short word, so conditions read naturally.

4.  A collection of x is xs, but only when x is also in scope.

5.  A reserved name may mean something else in a record, method or
    case that does not use it in its reserved meaning.  Qualified
    accessor calls do not count.

6.  Pattern variables take the name of the record or component they
    bind.


    Reserved

f, x          function and argument of an application
i, j          loop indices
s, t, u       terms
theta, sigma  substitutions
